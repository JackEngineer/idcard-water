# 隐私说明

本说明适用于证件水印 `0.1.0` 开发版本。应用的图片处理在本机执行，不提供上传、账户、遥测、自动更新或云端错误上报功能。

## 图片在应用内的流向

用户通过原生文件选择或原生拖入选择图片后，Rust 读取字节并建立内存会话。会话保留文件名和输入字节快照，不保留源文件路径。前端只接收会话标识、文件名、尺寸及 Rust 生成的预览，不接收输入路径或原文件字节。

未输入水印时，前端可显示最长边不超过 1600 像素的未加水印确认缩略图。该缩略图有明确标识，不能作为导出结果。有效水印的预览和导出使用同一个 Rust 合成流程。前端用内存 Blob 显示预览，替换和卸载时释放对象 URL。

导出使用本次原生目录选择产生的不透明目录令牌。前端不能传入任意文件路径写文件。已有文件不被覆盖。写入使用用户选择目录内的临时文件，内容已经加水印，再以不覆盖方式保留为结果。异常退出可能在所选目录留下已经加水印的临时文件，不承诺所有文件系统上的原子性或崩溃恢复。

导出失败重试使用原批次的水印配置，只重试失败项。移除图片后，重试不会从旧批次恢复输入字节。

## 不主动保存的内容

应用不提供最近文件、编辑历史、自动恢复或水印模板持久化。不使用 localStorage、sessionStorage、IndexedDB、数据库或持久化图像缓存保存图片、水印和接收方。应用不编写包含这些内容的业务日志，不加载远程字体或脚本。

关闭窗口会结束会话并释放进程资源。这不等于安全擦除内存、交换空间或磁盘。应用框架和操作系统可能产生 WebView 缓存、系统日志或崩溃转储。当前尚未完成所有平台的运行时缓存、临时目录和日志取证，不能据静态代码检查宣称系统绝无残留。

## 输出与元数据

应用先处理方向和颜色，再把水印合成为 RGB 像素。输出 JPEG 或 PNG 重新编码，不复制源文件 EXIF、GPS、XMP、IPTC、注释、嵌入缩略图或预览图。

已经使用带虚构 GPS、方向、XMP、IPTC、注释和未加水印缩略图的合成输入，独立检查实际 JPEG 和 PNG 输出。检查使用 ExifTool，可通过 `npm run verify:fixtures` 重复。检查不能保证未来任意版本和任意图片都没有缺陷。

## 运行时联网边界

生产配置只允许本地 Tauri IPC，没有前端通用 HTTP、shell、文件系统或事件监听权限。应用不初始化网络、打开外部链接、自动更新或云端错误收集插件。

开发服务器、依赖安装、构建工具和操作系统更新可能联网，不属于用户图片处理功能。浏览器合成验收页通过回环地址调用 Rust，只用于开发验证，不进入生产入口。

当前已有生产配置及源码静态检查，尚未完成成品在断网环境的原生全流程和覆盖 WebView 子进程的网络捕获。操作系统网络活动不能直接归因于应用，也不能仅凭一次未观察到连接就证明应用始终不联网。

## 应用不能控制的风险

- 保存目录可能属于 iCloud Drive、OneDrive 或其他同步、备份服务。操作系统可上传导出文件，应用无法禁止。
- 接收方仍可转发、截图、裁剪、编辑或尝试移除水印。用途文字不构成绝对防护或法律保证。
- 操作系统、输入法、剪贴板工具、屏幕录制、交换内存及恶意软件可能接触敏感内容。
- 发送工具可能再次压缩图片。发送前检查水印与关键信息是否清晰。

所有自动化测试和示例均使用虚构信息。不要把真实身份证、实际接收方、水印用途文本、源路径或私密截图提交到公开仓库或 CI。
